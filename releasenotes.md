# MotoLogg v1.0.0 Release Notes

### 🚀 What's New:
- **Feature Overview & Guide**: Interactive walkthrough showcasing core features on first launch (accessible anytime in Settings).
- **Automated Bank SMS Detection**: 1-tap notification quick-save with instant transaction parsing.
- **Smart Duplicate Shield**: Prevent duplicate expenses across UPI, Card, and Cash entries.
- **Mileage & Fuel Efficiency Tracker**: Real-time km/L calculation and cost per kilometer.
- **Multi-Bike Garage**: Track and switch between different motorcycles with cloud backup.
- **Bug Fixes & UI Polish**: Smoothed expense saving loaders, industrial dark mode animations.
